# Shared thresholds and rules (single source of truth)

Every the advertiser Google Ads skill reads its numbers from this file. Skills
**must not** hard-code their own thresholds, so the setup, diagnostic, reviewer
and planning agents never disagree.

> Status: DRAFT v0.1 for the the advertiser workshop. Values marked **G** or
> **W** must be confirmed (G) or agreed with the advertiser (W) before use.

## Source labels

Label | Meaning                                                                                                                                                | Can be shared externally?
----- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------
**P** | Public Google documentation (Google Ads Help, Merchant Center Help, Google Ads API docs). The page title is given; confirm the link before publishing. | Yes
**G** | Google best-practice guidance used by account teams. Public wording still to be confirmed.                                                             | Only after confirming public wording
**W** | Working rule proposed for the advertiser. **Not Google policy.** Calibrate during the pilot.                                                           | Yes, labelled as a proposal
**C** | Client rule set by the advertiser. Lives in `client_rules.md`.                                                                                         | Client-owned

## Verdict levels

-   **PASS**: meets the rule.
-   **WARN**: allowed, but the reviewer must show the finding to the approver.
-   **BLOCK**: do not apply the change until it's fixed, or a named human with
    the right approval tier overrides it in writing (see EXE-05).
-   **NOT_ASSESSED**: data unavailable. Never report missing data as PASS.
